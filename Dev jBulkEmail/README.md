## 🛠️ Choice A: The Standalone Build (Recommended)
Use this method to create a version of the app that runs on **any laptop**, even if it does not have Python installed.

### 📦 How to Build the Master Package
1.  **Execute the Build**: Double-click the file named `BuildExecutable.bat`.
2.  **Wait for Construction**: A terminal will open and bundle the Python engine automatically.
3.  **Locate the Output**: 
    - Open the folder: `PACKAGE_READY_TO_ZIP/`
4.  **Deploy**: 
    - Inside that folder, you will find a folder named `jBulkEmailSender`. 
    - **Zip this folder.**
    - Send this zip file to any other laptop.
5.  **Running**: The person receiving it unzips the folder and runs **`Deploy_Mission_Control.vbs`**.
6.  **Confirmation**: A professional wizard will confirm the installation and create a desktop icon automatically.
