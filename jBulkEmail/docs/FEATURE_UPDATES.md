# Bulk Email Sender - Feature Updates

## Version 5.4 - Architecture Refactoring
- **Codebase Optimization**: Moved all rich text formatting logic to `RichContentManager.py` to make the main application lighter and more maintainable.
- **Default HTML Mode**: HTML mode is now enabled by default for all new emails.
- **Rich Text Editor Class**: Centralized editor logic including toolbar, shortcuts, and HTML generation.

## Version 5.3 - Advanced Formatting
- **🎨 Color Picker**: Change text color to any custom color.
- **[11 ⌄] Size Selector**: Change font size (8pt to 36pt).

## Version 5.2 - Smart Paste & Auto-Link
- **File Paste**: Copy image file -> Paste insert image.
- **Auto-Link**: Type URL -> Enter -> Blue Link.

## Version 5.1 - WYSIWYG
- Visual editor with no HTML tags.
