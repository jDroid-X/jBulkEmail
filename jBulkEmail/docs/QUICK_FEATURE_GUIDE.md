# Quick Feature Summary

## ✅ Latest Updates (WYSIWYG Edition)

### 1. **True Visual Editor**
   - **No more `<b>` tags!** Text formatting like **Bold** and *Italic* appears directly as styled text.
   - **Visual Links**: URLs become blue and clickable.
   - **Inline Images**: Images appear directly in the editor, not as placeholders.

### 2. **Auto-Link Detection** (New!)
   - Type a URL (e.g. `https://google.com`) and press **Enter**.
   - The line automatically turns **blue and underlined**.
   - You can click it to open in your browser to test it.

### 3. **Smart Image Paste** (New!)
   - **From Folder**: Copy an image file from Windows Explorer → Paste in editor. It just works!
   - **From Screenshot**: Copy a screenshot → Paste. Works instantly.

### 4. **Batch Safety**
   - **"Safety Pause between Batches"**: System pauses to prevent spam blocks, then **resumes automatically**.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+B` | **Bold** |
| `Ctrl+I` | *Italic* |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Tab`    | Indent → |
| `Shift+Tab`| ← Un-indent |
| `Enter`  | New line (Auto-links URLs) |

## 🖱️ Tips

- **Check HTML Mode**: The "HTML Mode" box is checked automatically when you use formatting. Keep it checked!
- **Click Links**: You can click the blue links in the editor to verifying them.
- **Images**: Drag & Drop is not supported yet, but **Copy & Paste file** works perfectly.
